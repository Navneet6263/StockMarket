SCANNER BLOCKING FIX - COMPLETE IMPLEMENTATION SUMMARY
======================================================

PROBLEM STATEMENT:
The market scanner was blocking FastAPI's event loop, causing ALL API endpoints to timeout when scanning.
Users saw empty dashboards because endpoints like /api/market/live-entries and /api/market/hot-picks
returned nothing during scans.

ROOT CAUSES IDENTIFIED:
1. Scanner ran synchronously in main thread, blocking FastAPI workers
2. time.sleep(0.2) in ThreadPoolExecutor blocked worker threads during AngelOne API calls
3. No delisted stock cache - scanner wasted time on 100+ dead symbols every scan
4. GTF zone detector crashed with NoneType errors when OHLC columns had None values
5. API endpoints waited for full scan instead of reading from cache

FIXES IMPLEMENTED:
==================

FIX 1 - Thread-Safe In-Memory Cache (market_hub.py)
----------------------------------------------------
CHANGED: Added thread-safe cache attributes to __init__:

  self._hot_picks_cache: Dict = {}

ADDED: get_live_entries() method for instant cache reads:

ADDED: get_hot_picks() method for instant cache reads:
  def get_hot_picks(self) -> Dict:
      with self._cache_lock:
          return {
              **self._hot_picks_cache.copy(),
              "scanning": self._is_scanning,
              "last_updated": self._last_scan_time,
          }

CHANGED: _refresh_scan_market() now sets scanning flags:
  At start:
    with self._cache_lock:

  At end (before return):
    with self._cache_lock:

CHANGED: scan_market() exception handler now clears scanning flag:

FIX 2 - Non-Blocking AngelOne Rate Limiting (market_hub.py)
------------------------------------------------------------
BEFORE:
  def fetch_live_quote(symbol: str):
      with api_semaphore:
          with count_lock:
              request_count += 1
              if request_count % 50 == 0:
                  time.sleep(2.0)  # BLOCKED WORKER THREAD
              else:
                  time.sleep(0.2)  # BLOCKED WORKER THREAD
  
  with ThreadPoolExecutor(max_workers=3):
      for symbol in top_symbols:
          futures.append(executor.submit(fetch_live_quote, symbol))

AFTER:
  def fetch_live_quote(symbol: str):
      with api_semaphore:
          try:
              return symbol, self.data.fetch_live_snapshot(symbol)
          except Exception as exc:
              if "Access denied" in str(exc):
                  logger.warning("Access denied for %s, skipping", symbol)
              return None
  
  with ThreadPoolExecutor(max_workers=5):  # Increased from 3
      for idx, symbol in enumerate(top_symbols):
          # Rate limit BETWEEN submissions, not inside tasks
          if idx > 0 and idx % 50 == 0:
              time.sleep(2.0)
          elif idx > 0:
              time.sleep(0.3)  # Increased from 0.2
          futures.append(executor.submit(fetch_live_quote, symbol))

CHANGES:
- Moved time.sleep() OUTSIDE the worker function (now in main thread before submission)
- Increased max_workers from 3 to 5 (workers no longer block)
- Removed 5-second sleep on "Access denied" (just skip and continue)
- Removed count_lock (no longer needed)

FIX 4 - GTF Zone Detector NoneType Fix (zone_detector.py)
----------------------------------------------------------
BEFORE:

      try:
          if history is None or history.empty or len(history) < 3:

          # float() operations would crash on None values

AFTER:
  def detect_zones(self, history: pd.DataFrame, max_lookback: int = 150):
      try:
          if history is None or history.empty or len(history) < 3:
              return []
          
          # Drop rows with None/NaN in OHLC columns BEFORE processing
          history = history.dropna(subset=['open', 'high', 'low', 'close'])
          if len(history) < 3:
              return []
          
          df = self._classify_candles(history.tail(max_lookback)).reset_index()

CHANGE: Added dropna() before any float operations to prevent NoneType errors
